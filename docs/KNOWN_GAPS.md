# Known gaps and verification boundaries

| Area                 | State / next step                                                                                                                                                                                                                                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Keyless AI           | `NOT_IMPLEMENTED` **in demo mode only:** live model tutoring, question synthesis, semantic short-answer grading, model-driven planning, and model-written recap. Their labelled demo alternatives are implemented, not silent fallbacks for a failed live request. See `lib/tutor.ts`, `lib/quiz.ts`, `lib/plan.ts`, and `lib/summary.ts`. |
| Live Gemini          | Provider code is implemented via the documented compatibility endpoint. **NOT RUN:** real embeddings, JSON Schema responses, rubric grading, provider usage reporting and the live first-token benchmark. Supply a server-side key and run the labelled evaluation before rollout.                                                         |
| GitHub / Vercel      | A local Git repository and pinned Actions workflow are provided. **NOT RUN:** remote push, hosted CI, Vercel deployment, and cloud Firebase / Google OAuth. No authorized repository, Vercel project, or cloud credentials were provided.                                                                                                  |
| Docker               | Configuration is included, but a container build/start is **NOT RUN** because no Docker runtime is available here. The same standalone Node bundle is exercised by local CI without Docker.                                                                                                                                                |
| Curriculum           | Generative AI is the only seeded track. Web and Data require an imported catalog. After import, changed chunks are not eligible for citations until indexed. Management commands are intentionally operational and explicit.                                                                                                               |
| Scale and retention  | The cohort view and learner histories use bounded reads and no asynchronous rollups. Chat retains a bounded recent history. Implement an institutional retention policy and batch analytics before wider deployment.                                                                                                                       |
| Replanning and recap | Replanning runs when the learner opens the overview or plan, not on a timer. The recap is on demand and cached against its inputs. Dates and streak accounting use UTC.                                                                                                                                                                    |
| Certificate          | In-app evidence of completion only. The current PDF standard font accepts Latin-script display names; names that cannot be encoded produce an explicit validation error.                                                                                                                                                                   |
| Grounding and safety | Citation labels measure source selection, not sentence-level entailment. Prompt separation, source allowlists and cheap attack-pattern checks reduce risk but cannot establish that all untrusted prompts are safe. Add adversarial and claim-level human tests with a real provider.                                                      |
